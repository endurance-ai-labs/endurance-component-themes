# Endurance component themes

The Foundations theme gallery now lives in the unified design product:

https://design.endurancelabs.ai/themes

This repo still deploys to `endurance-component-themes-gallery.vercel.app`.
Every request on that hostname is a permanent redirect (308) to `/themes` on
`design.endurancelabs.ai`, so one Endurance session covers the gallery and the
UI Library.

Do not add gallery pages here. Change the gallery in
[endurance-UI-Library-and-agent](https://github.com/endurance-ai-labs/endurance-UI-Library-and-agent).
